# ⚡ Counter App
A simple, intuitive, and responsive Counter App built with React.js and Tailwind CSS. Easily increment, decrement, and reset your counter with smooth animations and a clean UI! 🖱️

---

## 📌 Features
✅ Increment and Decrement Counter  
✅ Reset Functionality  
✅ Responsive UI (TailwindCSS)  
✅ Real-Time Counter Update  
✅ Smooth Button Animations and Hover Effects
