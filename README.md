⚡ Counter App
A simple, intuitive, and responsive Counter App built with React.js and Tailwind CSS. Easily increment, decrement, and reset your counter with smooth animations and a clean UI! 🖱️

📌 Features
✅ Increment and Decrement Counter
✅ Reset Functionality
✅ Responsive UI (TailwindCSS)
✅ Real-Time Counter Update
✅ Smooth Button Animations and Hover Effects

🚀 Getting Started
Follow these steps to set up and run the project locally:

📂 1. Clone the Repository

git clone https://github.com/balajii-dev/Counter.git
cd Counter


🏗 2. Install Dependencies

npm install


▶️ 3. Run the App

npm run dev


🛠 Tech Stack
Frontend: React.js (Vite), Tailwind CSS
Logic: JavaScript (useState Hooks for Counter Functionality)
